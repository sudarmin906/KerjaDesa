Fitur:

- Data kegiatan
- Monitoring lapangan
- GPS
- Offline/localStorage
- PWA install ke layar utama

PENTING:
PWA membutuhkan HTTPS atau localhost agar service worker aktif. Untuk penggunaan online dari HP,
unggah folder ini ke hosting statis HTTPS seperti GitHub Pages, Netlify, Vercel, atau hosting web Anda.

Jika dibuka melalui URL HTTPS di Chrome:
1. Login.
2. Tambahkan kegiatan.
3. Buka Monitoring.
4. Ambil GPS (izinkan lokasi).
5. Simpan.
6. Data tetap tersedia saat offline setelah cache pertama.

Versi ini adalah fondasi aplikasi HP. Sinkronisasi ke server KerjaDesa V3 dapat dihubungkan pada tahap berikutnya.
