KERJADESA V4 - DRP OTOMATIS

Login demo: admin / admin123

Fitur utama:
- Upload DRP bulanan PDF/Word/Excel/TXT.
- Untuk DRP PDF format laporan TPP yang digunakan pada uji ini, aplikasi membaca identitas, ringkasan, aktivitas dan kunjungan lapangan.
- Setelah DRP diproses, data kegiatan otomatis masuk ke daftar Kegiatan dan identitas laporan.
- Menampilkan pratinjau hasil pembacaan sebelum laporan dibuat.
- Upload SPPD disiapkan sebagai sumber kedua; pemetaan SPPD akan dikembangkan setelah format SPPD dikunci.
- Output Word dan Cetak/Simpan sebagai PDF.
- Data tersimpan lokal di perangkat.

Catatan:
- Sistem tidak mengarang data yang tidak ditemukan dalam dokumen.
- Jika format DRP berubah jauh dari format uji, hasil baca perlu ditinjau.
